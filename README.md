# Sentinel Music Server

Серверная часть экосистемы **Sentinel Music** — полнофункциональный self-hosted сервер музыкального стриминга с умными векторными рекомендациями («Поток»), синхронизированными текстами песен и встроенным веб-плеером.

---

## ⚡ Особенности

- **Потоковый стриминг:** Поддержка HTTP 206 Partial Content (перемотка без задержек, поддержка тяжелых FLAC и MP3).
- **Векторные рекомендации («Поток»):** Векторизация аудио (BPM, спектральные характеристики, тембр) на базе PostgreSQL + pgvector и косинусного сходства.
- **Синхронизированные тексты песен:** Интеграция с открытой базой караоке-текстов LRCLIB и многоуровневое кэширование (.lrc + SQLite/PostgreSQL).
- **Фоновый Watchdog:** Автоматическое обнаружение новых треков в папке фонотеки с дебаунсом (защита от чтения недокачанных файлов).
- **Встроенный Web-плеер:** Адаптивный веб-интерфейс с поддержкой караоке, плейлистов и режима «Поток».
- **Модульная система плагинов:** Изолированная загрузка сторонних источников, скраперов и провайдеров метаданных.
- **Безопасность (Zero Hardcode):** Автоматическая генерация надежных паролей и токенов без хранения секретов в репозитории.

## 🚀 Быстрый старт (Docker)

### 1. Автоматическая генерация конфигурации (.env)
Выполните скрипт генерации криптостойких паролей для базы данных:
```bash
python setup_env.py
```
Скрипт создаст `.env` с уникальными паролями PostgreSQL и секретным ключом приложения.
В `.env` при необходимости укажите путь к каталогу вашей локальной фонотеки:
```env
MUSIC_DIR=/path/to/your/music
```

### 2. Запуск контейнеров
```bash
docker compose up -d --build
```

Сервер автоматически:
1. Запустит базу данных **PostgreSQL 16 с pgvector**.
2. Дождется готовности БД и запустит контейнер FastAPI-сервера.
3. При первом старте сгенерирует учетные данные администратора и выведет их в логи (`docker compose logs -f music-server`).
4. Запустит веб-интерфейс и REST API по адресу `http://localhost:8000`.

## 📦 Локальная разработка без Docker

```bash
# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# или .venv\Scripts\activate на Windows

# Установка зависимостей
pip install -r requirements.txt

# Запуск тестов
pytest

# Запуск сервера
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
